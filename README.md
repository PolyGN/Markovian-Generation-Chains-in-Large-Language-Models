# Markovian Generation Chains in Large Language Models

[![arXiv](https://img.shields.io/badge/arXiv-2603.11228-b31b1b.svg)](https://arxiv.org/abs/2603.11228)

[Markovian Generation Chains in Large Language Models](https://arxiv.org/abs/2603.11228).

We study how texts evolve when repeatedly processed by LLMs, where each step takes a fixed prompt and the previous output as input, with no memory of earlier steps. Through iterative rephrasing and round-trip translation, we find that outputs either converge to a small recurrent set or keep producing novel sentences, and that the process can increase or reduce sentence diversity depending on temperature and the initial input.
